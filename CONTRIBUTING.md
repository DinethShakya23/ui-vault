# Contributing

Thanks for helping keep this list useful.

## Guidelines

- **One entry per pull request**, unless you're fixing several broken links.
- Add the entry to the **most specific section** it fits.
- Use this format:

  ```markdown
  - [Name](https://link) — Short description ending with a period. 🆓⚛️
  ```

- Keep descriptions under ~15 words, factual, and free of marketing language.
- Add the right legend tags: 🆓 free/OSS · 💎 paid tier · ⚛️ React · 🟢 Vue · 🧡 Svelte · 🅰️ Angular · 🌐 framework-agnostic.
- The project must be **actively maintained** (a release or meaningful commit in the last 12 months) and have real documentation.
- Link to the official site, not a blog post or aggregator.
- Check spelling and that the link works.

## Removing entries

Open a PR if a project is archived, deprecated, or has been renamed — include a link showing the change.
