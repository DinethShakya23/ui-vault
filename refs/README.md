# refs/

Manual references that appear in the [gallery](../gallery/README.md).

- `refs/<slug>/` — files for one entry (run `npm run slugs <name>` to find its slug).
- `refs/board/` — anything else worth referencing; subfolders become headings on the [Reference Board](../gallery/board.md).

Images (`png jpg webp gif svg avif`) are shown inline; videos (`mp4 webm mov`) are linked. File names become captions. See [CONTRIBUTING.md](../CONTRIBUTING.md#adding-references) for the full guide.
